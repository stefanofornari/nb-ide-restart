# US0008 - Restart immediately without confirmation dialog

### User Story
```
AS A user
I WANT to restart the IDE without a confirmation dialog
SO THAT I save time and reduce unnecessary clicks
```

#### Status
DONE

#### Dependencies
- US0007

#### Notes
1. Modify the **"Restart"** menu item to include two options:
   - **"Restart Now"** → Restarts immediately after confirmation.
   - **"Restart Now and Don’t Ask Again"** → Restarts immediately and saves the preference.
2. Store the preference `ste.nb-ide-restart.confirm` using the **NetBeans Preferences API**.
3. If the preference is set to `"no"`, **skip the confirmation dialog** and restart immediately.

### Acceptance Criteria

1. **Primary action: restart and remember**
   ```
   **GIVEN** no preference is set
   **WHEN** the "Restart" action is selected from the NetBeans menu
   **EXPECT** the popup with the countdown appears.
   **WHEN** the user clicks "Restart Now and Don’t Ask Again"
   **EXPECT**
   - The IDE restarts immediately.
   - The preference `ste.nb-ide-restart.confirm` is set to "no".
   ```

2. **Primary action: restart without confirmation dialog**
   ```
   **GIVEN** the preference `ste.nb-ide-restart.confirm` is set to "no"
   **WHEN** the "Restart" action is selected from the NetBeans menu
   **EXPECT**
   - No confirmation popup appears.
   - The IDE restarts immediately.
   ```
