# US0007 - Add restart action to NetBeans

### User Story
```
AS A user
I WANT to restart the IDE from an IDE menu
SO THAT I do not have to select Exit and then relaunch the IDE
```

#### Status
DONE

#### Notes
1. Add a "Restart" menu item to the **File** menu.
2. Add an icon to the action.
3. Provide a **countdown confirmation dialog** before restarting.
4. Allow the user to **cancel** the action within the countdown period.

### Acceptance Criteria

1. **Primary action: restart**
   ```
   **WHEN** the "Restart" action is selected from the NetBeans menu
   **EXPECT**
   - A confirmation popup with a countdown appears.
   - The IDE restarts automatically when the countdown reaches 0.
   ```

2. **Primary action: restart now**
   ```
   **GIVEN** no preference is set
   **WHEN** the "Restart" action is selected from the NetBeans menu
   **EXPECT** the popup with the countdown appears.
   **WHEN** the user clicks "Restart Now"
   **EXPECT** the IDE restarts immediately.
   ```

3. **Primary action: cancel**
   ```
   **GIVEN** no preference is set
   **WHEN** the "Restart" action is selected from the NetBeans menu
   **EXPECT** the popup with the countdown appears.
   **WHEN** the user clicks "Cancel"
   **EXPECT**
   - The popup closes.
   - The IDE does not restart.
   ```
