# US0009 - Manage restart confirmation in Options dialog

### User Story
```
AS A user
I WANT to easily re-enable the confirmation dialog via the IDE settings
SO THAT I don't have to manually edit preference files if I change my mind about skipping confirmation
```

#### Status
TO BE DONE

#### Dependencies
- US0008

#### Notes
1. Add a new panel or add to existing panel in **Tools → Options**.
2. Add a checkbox: **"Show confirmation dialog on Restart"**.
3. Binding:
   - Checked: `ste.nb-ide-restart.confirm` = `"yes"` (or removed).
   - Unchecked: `ste.nb-ide-restart.confirm` = `"no"`.

### Acceptance Criteria

1. **Manage preference via Options**
   ```
   **GIVEN** the user has previously set "Don't Ask Again"
   **WHEN** the user opens Tools -> Options -> [Plugin Settings Panel]
   **EXPECT**
   - The "Show confirmation dialog on Restart" checkbox is present.
   - The checkbox is unchecked.
   **WHEN** the user checks the box and clicks OK
   **EXPECT**
   - The preference `ste.nb-ide-restart.confirm` is updated.
   - The next time the user restarts the IDE, the confirmation dialog appears.
   ```
